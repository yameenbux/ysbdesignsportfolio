- **App** — https://yameenbux.github.io/Taiyabah-Mosque-App/

## 🛠️ Built with

- Single-file, dependency-free **HTML / CSS / JavaScript** — no build step
- Fully responsive and accessible (visible keyboard focus, reduced-motion support)
- Deployed on **GitHub Pages**

## 🌐 Deployment

Served from `index.html` on the `main` branch via **Settings → Pages → Deploy from a branch → `main` / `root`**.
A custom domain (e.g. `ysbdesigns.co.uk`) can be pointed at it later in the same settings.
